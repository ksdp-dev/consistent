# Consistent

> A minimal productivity and habit-tracking app designed to help you build routines, track progress, maintain streaks, and stay consistent every day.

## ✨ Overview

**Consistent** is a personal productivity app built around one simple idea:

> **Consistency beats intensity.**

The app helps users turn daily tasks and routines into measurable progress through completion tracking, streaks, weekly consistency, and performance insights.

It is designed to stay focused, simple, and distraction-free rather than becoming another complicated productivity tool.
